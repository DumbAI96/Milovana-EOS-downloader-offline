Saved listing pages for Q mode live here.

In your browser: open a search / author / tag page, then Ctrl+S and save it
into this folder as "Webpage, Single File (.mhtml)" or "Webpage, HTML only".

Q mode reads the title / author / description / tags of every tease found on
those pages - no typing needed. Re-save a page any time; it is picked up on
the next link you paste in Q mode.

(These pages are yours - the folder is ignored by git.)
